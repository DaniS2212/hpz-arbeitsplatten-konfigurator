**Before any L/U geometry, edge, connector, measure, price or production change:**

1. Read [the Speedmaster reference register](docs/references/speedmaster-lu/README.md), [the recorded decisions](docs/references/speedmaster-lu/DEVELOPMENT_CONTEXT.md), and [the open supplier evidence](docs/references/speedmaster-lu/EVIDENCE_GAPS.md). Use the already checked-in technical assertions in `docs/l-speedmaster-screenshot-evidence-20261102.md` and `docs/l-speedmaster-visual-parity-20261102.md`.
2. The **60 original reference screenshots** (48 supplier Speedmaster + 12 shop/UI comparisons) are stored in GitHub as the verified ZIP `docs/references/speedmaster-lu/Speedmaster_PR39_GitHub_Upload.zip` (SHA-256 `c32267e1dba0b8374f3215002b1505675b364a589d3128954feba5db34b4f9eb`). **Before comparing visuals**, check out the private repository and extract locally with `python scripts/import_speedmaster_reference_zip.py import docs/references/speedmaster-lu/Speedmaster_PR39_GitHub_Upload.zip` followed by `python scripts/import_speedmaster_reference_zip.py verify-tree`. Use `SOURCE_MANIFEST.csv` for individual file names, hashes and descriptions. The ZIP stores PNGs in directories within the archive; they are **not** individually committed. A text-only GitHub connector may not display binary images: obtain actual pixels before claiming a visual sign-off. Never treat our own `shop-ui` screenshots as supplier references.
3. Treat confirmations, visual observations, inferred geometry, and missing supplier information as four distinct evidence categories. Before any L/U supplier handoff or checkout-development work, run `node scripts/speedmaster-closeout.mjs --check` and read `docs/references/speedmaster-lu/SUPPLIER_CLOSEOUT.json`. The checklist is private and read-only. A filled record never turns on CNC, WooCommerce or prices.
 Every new shape/feature must be proven with source configuration + independent geometric/browser test + manual comparison. A passed test of our own model does not prove actual supplier manufacture.
4. Never infer CNC operations, connector counts, cut-piece dimensions, shipping package counts, prices or supplier limits from illustrations alone.
5. The **straight countertop (Gerade)** is the established UI/design template and has a separate live WooCommerce sales path; do not change that behavior as part of L/U previews. Keep L/U in non-purchasable test mode until explicit approval and supplier/checkout evidence.
6. Any behavior change follows a failing test, minimal fix, then full relevant test and WordPress bundle check. Do not publish or merge without explicit user approval.
7. Design rule: identical cards, type, step navigation, surfaces, mobile UX and summaries to Gerade; only form-specific geometry/fields differ. Preserve L's larger visual preview and active-dimension highlight when sound.
